# XDK Tchac — téléchargements

**Tchac !** est un jeu de cartes à ventouse, fait maison et gratuit, pensé pour les enfants de 4 à 7 ans avec un
**syndrome 22q11**. Le logiciel dit les consignes à voix haute, par exemple « Le bateau sur la carte jaune ! ». Les
enfants cherchent la carte sur la table et la tapent avec leur baguette à ventouse : tchac !

## Il faut le code d'accès

Les fichiers de ce dépôt sont **chiffrés** : sans le code d'accès donné aux familles par la TEAM XDK, ils ne
s'ouvrent pas. Le même code ouvre tous les jeux pour enfants (Tchac !, Petits Pas).

- 💻 **PC (Windows 10 et 11)** : installe [XDK Hub](https://github.com/XDTEAMDev/XDK-Hub-releases/releases/latest),
  va dans **Jeux pour enfants**, choisis **Tchac !** et tape le code. Le hub s'en souvient et garde le jeu à jour.
- 📱 **Android** et 🌐 **navigateur** : ouvre **https://xdteamdev.github.io/XDK-Tchac-releases/** et tape le code.
  Tu peux y jouer tout de suite, télécharger l'appli Android (`XDKTchac.apk`) et les cartes à imprimer.

## Les cartes à imprimer

Sur la même page, **Cartes à imprimer** donne le PDF de 12 pages : les règles, les feuilles de consignes et 72 cartes.

1. Imprime les pages 5 à 12 en couleur, à la taille réelle (100 %).
2. Plastifie les feuilles entières : la ventouse ne colle que sur une surface lisse.
3. Découpe les cartes. Il faut aussi une baguette à ventouse par joueur.

## Ce qu'il fait

- Deux paquets : 👂 **Pièges des oreilles** (des mots qui sonnent presque pareil : bateau, gâteau, château, chapeau…)
  et 👀 **Pièges des yeux** (des images qui se ressemblent : lune, banane, croissant…).
- Tu choisis les familles posées sur la table : la voix ne parle que de celles-là.
- **3 niveaux** : l'image seule, l'image et la couleur, puis deux cartes à la suite.
- Voix lente ou normale, consigne dite une ou deux fois, bouton pour voir la bonne carte.
- Marche **sans Internet** une fois installé. Rien n'est envoyé : les réglages restent sur l'appareil.

Ce jeu complète le travail de l'orthophoniste, il ne le remplace pas.
